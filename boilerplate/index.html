Как это работает

Слои стоят друг над другом

prepare_layers.py только режет один assets/atlas.png на 4 квадранта и проверяет alpha. Если overlay пришёл с фоном, фон удаляется через MCP Recraft, без локального вырезания.

Текущий источник

Нарезка из atlas

Исходник: assets/atlas.png. Результат нарезки: background.png, far.png, near.png, mug.png как основной портретный слой. Отчёт проверки лежит в assets/layers-report.json.
